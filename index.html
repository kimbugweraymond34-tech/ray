Web Development

In web development, we shall be learning how to create a structure for websites using HTML, CSS, and JavaScript.

HTML

  • HTML
  • CSS
  • JavaScript

HTML

HTML stands for HyperText Markup Language. It is used to create the structure of webpages.

HTML allows us to add headings, paragraphs, images, links, tables, forms, and other elements to a webpage.

CSS

CSS stands for Cascading Style Sheets. It is used to style webpages by controlling colors, fonts, spacing, and layouts.

JavaScript

JavaScript is a programming language that makes webpages interactive and dynamic.
